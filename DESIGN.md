# Portfolio Design System Guardrails
- Avoid standard AI design tropes (no absolute-black backgrounds, no neon-glow cards).
- Use high-fidelity micro-interactions (magnetic hovers, layout transitions using Framer Motion).
- Background: Strict dot-matrix grid with mouse-tracking radial spotlight.
- System Layout: Premium Bento-grid with clean hairline borders (1px border-neutral-800).
